# HR Attrition Analysis – Power BI

## 📌 Project Overview
This project analyzes employee attrition to identify key drivers of turnover and workforce patterns.  
The report is designed to support HR and management in making data-driven retention decisions.

---

## 🧩 Dataset & Modeling
- Source: HR flat-file dataset
- Created Fact and Dimension tables from a flat file
- Built a **Star Schema** data model
- Established one-to-many relationships
- Created a dedicated **Measures Table** for all KPIs
